# Code of Conduct

This repository is a place to learn, compare solutions, and help other developers.

Be respectful in issues, pull requests, and reviews. Give constructive feedback about code and ideas. Harassment, personal attacks, discrimination, and sharing someone else's private information are not welcome.

Report conduct concerns privately to [shubhagamansingh@gmail.com](mailto:shubhagamansingh@gmail.com). The maintainer may remove inappropriate content or limit participation. Reports will be handled privately as far as practical.
