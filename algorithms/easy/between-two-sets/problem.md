# Between Two Sets

[Read the full problem on HackerRank](https://www.hackerrank.com/challenges/between-two-sets/problem)

- **Category:** Algorithms
- **Difficulty:** Easy

## Problem in your own words

Given two integer arrays, count the positive integers that every value in the first array divides and that, in turn, divide every value in the second array.

## Input and output

The function receives two arrays, `a` and `b`, and returns the number of integers satisfying both divisibility conditions.

## Example

For `a = [2, 6]` and `b = [36, 72]`, the valid integers are `6`, `12`, `18`, and `36`. The result is `4`.
