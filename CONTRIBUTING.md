# Contributing

Corrections and original solutions are welcome. Please check the challenge index and open issues before starting so work is not duplicated.

## Add a solution

1. Use the official HackerRank challenge URL. Do not copy the full problem statement, editorial, or another person's solution into this repository.
2. Place your code in `<category>/<difficulty>/<problem-slug>/solution.<extension>`. Use lowercase folder names with hyphens and no numeric prefix.
3. Add a row to the challenge index in the root `README.md`, using the next three-digit ID. Link the challenge title to HackerRank and the code cell to your solution file.
4. Keep the solution readable and remove unfinished placeholder comments. Describe the main idea and its time and space complexity in your pull request.
5. Check the solution against the challenge examples or submit it to HackerRank. Include the result in your pull request.

The maintainer refreshes the category and language badges after accepting new solutions. For a correction, explain the failing case and keep the change focused.

By contributing, you agree that your original contribution may be distributed under this repository's [MIT license](LICENSE). Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
